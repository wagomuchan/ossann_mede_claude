# おっさん観察箱庭 — 仕様書

おっさんの一人暮らしの部屋を、ただ眺めるだけのWebアプリ。

## コンセプト

- 見る側は**何もできない**。カメラ固定、ログなし、UIなし
- 時間は現実の **30倍** で進む（箱庭の1日 = 現実の48分）
- 箱庭の時刻は現実の時刻から計算する。タブを閉じてもおっさんの生活は続いており、誰がいつ開いても同じ瞬間を見ることになる
- 時刻が分かるのは、部屋の壁掛け時計だけ

## おっさん

| 項目 | 内容 |
|---|---|
| 年齢 | 45歳くらい |
| 職業 | リモートワーク（会社員） |
| 趣味 | ゲーム（ジャンルはいろいろ。タイトルはすべて架空） |
| 体型 | ちょっと太っている |
| 毛髪 | ハゲ始めている |
| 住まい | 1Kで完全に一人暮らし |
| 名前 | 設定上はあるが、ユーザーには絶対に見せない |
| 睡眠 | 箱庭時間で1日1時間で足りる体質 |

### 長い時間をかけた変化

現実の日数を基準にする（箱庭の日数を基準にすると速すぎるため）。

- 髪：ゆっくり減るだけで、増えることはない
- 体重：増えたり減ったりする

## 時間

- 箱庭時間 = 現実時間 × 30
- 動き（歩く・食べるなど）は普通の速さで見せる。時計だけが30倍で進む
- 箱庭にも曜日がある。平日は仕事、土日は休み
- 季節は現実の日付に合わせる。天気は箱庭の日ごとに決める

### 平日のスケジュール（目安）

| 時刻 | 行動 |
|---|---|
| 00:00〜 | 夜のゲーム（PCまたはTV） |
| 深夜 | 風呂、鏡で頭頂部チェック、冷蔵庫、トイレ |
| 早朝 | 窓の外が白んでくる。「あと1戦」 |
| 07:50 | 就寝 |
| 08:50 | 起床（始業ギリギリ）。シャツに着替える |
| 09:00 | 朝会（カメラON。この間だけ姿勢がいい） |
| 午前 | 仕事。カメラOFFになった瞬間に猫背 |
| 12:00 | 昼ごはん（カップ麺、出前など） |
| 午後 | 仕事。15時におやつ |
| 18:00 | 終業。即ゲーム |
| 夜 | 夕飯、ゲーム |

### 休日

- 起きる時間がバラバラ
- 洗濯をする、コンビニに出かける（その間、部屋は無人になる）
- ほぼずっとゲーム

## 見た目

- ローポリ3Dの箱庭（ミニチュアのような質感）
- 部屋の手前2面の壁は取り払った断面表示。カメラは手前右上から見下ろす位置で固定
- 光の演出：時間帯で窓から入る光が変わる。夜はモニターやTVの光が顔を照らす
- 季節の模様替え：夏は扇風機、冬はこたつとみかん、春は花粉症のティッシュ、など
- 小ネタ：宅配の伝票などの宛名は、絶対に読めない

## 音

- 最初に「のぞく」をクリックした時点で、音を出すことを許可してもらう（ブラウザの仕様のため）。それ以降はUIなし
- 環境音（エアコン、雨、季節の虫、鳥）、打鍵音、ため息、いびき、ドアの音、インターホンなど
- 効果音はすべてWeb Audioで生成し、外部の素材は使わない

## 技術

- Vite + TypeScript + Three.js
- 3Dモデルはすべてコードで生成する（外部の素材なし）
- 公開先はGitHub Pages
- スマホ対応：画面の縦横に合わせて画角を自動で調整し、描画の負荷に応じて画質を自動で切り替える

## 実装メモ

- 一日の予定は箱庭の日番号から決定的に作る（`src/brain/plan.ts`）。0時をまたぐゲームは前日と翌日でつながる
- 予定の頭で場所が変わる場合は歩く。歩く時間は経路の長さから決まる
- 長すぎるゲームの途中には、冷蔵庫かトイレの休憩をはさむ
- Tシャツは風呂上がりに着替える。仕事中はシャツ（会議でカメラに映るため）
- 無精ひげは月曜の朝に剃り、週末にかけて伸びる
- ゴミの日（火・金）は寝る前にゴミを出す
